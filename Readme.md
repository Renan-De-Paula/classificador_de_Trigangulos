🔺 Classificador de Triângulo em Python
Este script em Python analisa se três segmentos fornecidos podem formar um triângulo. Caso formem, ele identifica o tipo de triângulo: equilátero, isósceles ou escaleno. Um exercício clássico para entender condicionais compostas, lógica matemática e o Teorema da Desigualdade Triangular.

🔧 Funcionalidades

Solicita três valores representando segmentos de reta.

Verifica se os valores podem formar um triângulo.

Classifica o tipo de triângulo:

Equilátero: todos os lados iguais.

Isósceles: dois lados iguais.

Escaleno: todos os lados diferentes.

Retorna mensagem clara ao usuário.

📌 Exemplo de Uso

Primeiro segmento: 5
Segundo Segmento: 5
Terceiro Segmento: 5
Os seguimentos acima podem formar um TRIÂNGULO!
EQUILÁTERO

Primeiro segmento: 3
Segundo Segmento: 4
Terceiro Segmento: 7
Os seguimentos acima podem formar um TRIÂNGULO!
ESCALENO

Primeiro segmento: 1
Segundo Segmento: 2
Terceiro Segmento: 3
Os segmentos acima NÃO podem formar um TRIÂNGULO!
